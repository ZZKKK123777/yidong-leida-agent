# 全市场异动雷达智能体

`yidong-leida-agent` —— 扫全市场，**先给结论，再给口径**：一份快报，头条异动、
异动榜单、诚实说明，三段都写在明面上。

同一个作品有两种用法，**共用同一段评分引擎**（`app.js` 的 `scoreMarkets`，
命令行从源码逐字节提取复用，引擎一行未改）：

- **网页**（`index.html` + `app.js`）—— 给人看的星空雷达；
- **命令行 / 技能**（`agent.mjs` + `skills/quanshichang-yidong/SKILL.md`）—— 给 Agent 调用的。

## 一屏速览

| 问题 | 答案 |
|---|---|
| 它做什么 | 横截面扫描上千个交易对，按自研 0-100 综合异动强度排序，产出头条 + 榜单的异动快报 |
| 数据从哪来 | 四路探头：多平台对照（默认）+ 币安官方三路（公开行情 / 官方 CLI / 开源数据仓库） |
| 谁出的分 | 自研引擎（与网页版同一段代码）；数据层能拿官方的一律拿官方 |
| 怎么验 | 不用信文档 —— 三条命令看程序自报的通道标识，见 [AGENT.md](AGENT.md) |
| 要不要密钥 | 不要。全程只读公开数据，不接账户、不下单 |

## 它回答什么 / 不回答什么

**回答**：现在全市场哪些币在异动？谁涨得最凶、跌得最凶？成交最活跃的是哪些？
某币为什么出现在榜上（分位、涨跌幅、方向口径逐项可见）？

**不回答**：不预测价格走势；不给买卖点；不回答真实主动成交流向
（公开快照没有逐笔方向，`方向` 字段是价格涨跌方向口径，快报里明说）。

## 三条命令自查

```bash
node agent.mjs --live --json       # 看 via=official-rest（币安官方公开行情，实测 681 市场 / 0.9 秒）
node agent.mjs --skill --json      # 看 via=binance-cli（官方 CLI 真实被调用，实测 1.1 秒）
node agent.mjs --official --json   # 看 archive.anchor 是不是上一个已收盘交易日（T+1，不猜数）
```

没装官方 CLI 时程序会如实回退并在 JSON 里标 `requestedSource: "skill"`
—— 它宁可说自己没调成，也不会假装调过。完整自查步骤与真实输出样张见 [AGENT.md](AGENT.md)。

## 四路探头

| 敲什么 | 数据从哪来 | 口径 |
|---|---|---|
| `node agent.mjs` | 多平台公开行情对照（与网页版同源） | 实时快照，实测 1365 市场 / 0.9 秒 |
| `node agent.mjs --live` | 币安官方公开行情 `ticker/24hr` 全市场快照 | USDT 计价 + 24h 成交额 > $10,000 过滤 |
| `node agent.mjs --skill` | 官方技能 binance + 官方 CLI | 同上一份官方公开行情 |
| `node agent.mjs --official --max-coins 60` | 官方开源数据仓库（合约 K 线 + 持仓量） | **T+1**，截至上一交易日收盘 |

自然语言也认：`node agent.mjs "看看官方归档里的历史异动"` 自动选通道；
识别不出就静默走默认，绝不乱猜。评分公式公开在
[skills/quanshichang-yidong/SKILL.md](skills/quanshichang-yidong/SKILL.md)。

## 它用了币安官方的什么？（带实测证据）

| 官方资源 | 用在哪 | 实测证据 |
|---|---|---|
| 官方公开行情接口 **data-api.binance.vision** | `--live`：现货全市场快照 | 原始 3702 个交易对 → 过滤后 681 个 |
| 官方技能 **binance** + 官方 CLI | `--skill` 通道取数 | `via` 真实变为 `binance-cli`，端到端 1.1 秒 |
| 官方开源数据仓库 **data.binance.vision** | `--official`：合约 K 线 + 合约指标（持仓量美元值） | 锚定 2026-09-13，40 币拼齐 33 个，缺 7 个如实列出 |

准确的说法是 **数据层用官方资源、评分与结论层自研**，不说「基于官方 skill 开发」。
官方 20 个技能逐个核过、其余 19 个为什么没接入，见 [AGENT.md](AGENT.md) 的取舍表。

## 网页用法

星空 Web3 视觉的雷达页：定时自动扫描、支持「立即扫描」手动刷新、下次刷新倒计时；
支持按平台、涨跌方向、币种名称筛选；点击榜单任意币种展开异动简报
（现价、24h 涨跌幅、成交表现、买卖方向、异动等级、文字说明）。

公开接口可能受网络环境、地区策略或限频影响：**页面取不到数时自动切换演示数据**
保证仍可体验，切换时页面会如实声明当前展示的是演示数据 —— 不冒充实时。
命令行**不做**演示降级，取不到数就如实报错退出。

## 项目文件结构

```text
yidong-leida-agent/
├─ index.html                        # 网页入口
├─ styles.css                        # 页面样式与星空视觉
├─ app.js                            # 行情接入、异动算法与交互（评分引擎所在）
├─ agent.mjs                         # 命令行入口：四通道 + 自然语言 + 快报输出
├─ AGENT.md                          # 评审自查卡：三条命令 + 资源对照 + 20 技能取舍
├─ skills/quanshichang-yidong/SKILL.md  # 官方技能定义
├─ netlify.toml                      # Netlify 部署配置
└─ README.md / 项目说明.md            # 中文说明
```

## 本地运行

```bash
node agent.mjs                # 命令行快报（需要 Node.js 18+，零第三方依赖）
python -m http.server 8787    # 网页版：项目目录里起本地服务，浏览器开 http://127.0.0.1:8787/
```

网页版也可以直接双击 `index.html`，本地服务器更适合完整功能。
