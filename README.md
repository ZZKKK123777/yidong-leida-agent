# 全市场异动雷达智能体

> 币安 Agent 参赛作品 · 方向：数据分析

## 一、项目简介

全市场异动雷达智能体是一款面向数字资产盯盘场景的数据分析网页应用。

项目通过接入 Gate.io 与 Hyperliquid 的公开行情数据，持续扫描多个数字资产市场，识别价格快速变化、成交活跃度异常以及主动买卖方向变化，并按照综合异动强度进行排序。

当用户点击某个异动币种时，系统会自动聚合该币种的价格变化、成交量表现和买卖方向，生成一段简明的异动简报，帮助用户快速了解市场发生了什么。

## 二、核心功能

### 1. 多币种价格异动扫描

- 定时扫描两个公开行情平台的市场数据
- 识别急涨、急跌以及成交活跃度较高的币种
- 计算 0-100 分的综合异动强度
- 按异动强度从高到低排序
- 支持平台、涨跌方向和币种名称筛选

### 2. 异动聚合简报

点击异动榜单中的任意币种后，系统会生成对应的异动简报，内容包括：

- 当前价格
- 24 小时涨跌幅
- 成交量或成交额表现
- 主动买盘与主动卖盘方向
- 综合异动等级
- 对当前异动的简要文字说明

### 3. 持续监控与自动刷新

- 页面默认定时自动刷新
- 支持点击“立即扫描”手动刷新
- 页面展示下次刷新倒计时
- 数据源暂时不可访问时自动切换演示数据，保证页面仍可体验

## 三、数据来源

本项目使用以下公开只读行情接口：

- Gate.io：现货市场行情接口
- Hyperliquid：公开市场价格与资产行情接口

项目不接入用户账户，不要求登录，不涉及充值、提现或交易权限。

由于公开接口可能受到网络环境、地区策略、交易所维护或接口限频影响，页面提供了演示数据降级机制。

## 四、异动评分思路

综合异动强度主要参考以下因素：

1. 价格涨跌幅：价格变化越明显，异动贡献越高
2. 成交活跃度：成交额越大或活跃度越高，异动贡献越高
3. 主动买卖方向：根据行情中的涨跌和活跃度估算买盘或卖压方向
4. 数据源交叉观察：同时展示 Gate.io 和 Hyperliquid 的市场信息

本项目的评分用于观察和排序，不构成投资建议。
